**C64Renum** is a utility for renumbering Commodore 64 BASIC programs (.prg files). It is not designed to process hybrid files which contain both BASIC and assembly (machine language); only pure BASIC .prg files will be correctly processed. Currently it has no ability to open disk files such as .d64, etc.

**How to install**

Download the latest release (zip file) from the GitHub page. Extract the archive to a convenient folder on your system. The program is self-contained and does not have an installer. Optionally, create a shortcut to the C64Renum.exe file and place it on your Desktop or other location for ease of starting the program.

**Running C64Renum**

Start C64Renum and open any C64 BASIC (.prg) file. Prior to opening a file the first time, you can select the options you would like under File -> Settings. Most of the settings are self-explanatory. The most important for easy operation is to set the Input folder to the folder where you store your C64 BASIC programs and optionally the output folder used by C64Renum. The settings are saved and reloaded automatically the next time you use the program.

**Notes**

C64Renum is a Windows application which requires the .NET runtime and will not run natively on other platforms such as Mac OS or Linux. It may work with some crossover/emulator solution but this has not been tested.
